# IttiMath

**IttiMath** is a fun, web-based math game designed specifically for children to practice quick mental arithmetic on both desktop and mobile devices.

**Play it here:** [ittimath.github.io](https://ittimath.github.io/)

---

## Features
* **Child-Friendly Interface:** Clean layout with large, easy-to-read numbers and buttons. You click on the numbers instead of typing them on a keyboard.
* **Fully Responsive:** Play on the go via smartphone or tablet, or at home on a PC.
* **Quick Practice:** Perfect for daily exercises.
* **Zero Overhead:** No registration, no ads, no distractions, and no user data collected. Just pure fun.

## Built With
* HTML, CSS, and JavaScript, built in a very pragmatic way.
